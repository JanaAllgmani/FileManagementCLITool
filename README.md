# File Management CLI Tool

## Overview

Developed a command-line file management tool using Java to perform common file operations efficiently.

## Technologies

* Java
* Java File I/O
* Java NIO

## Features

* List files and directories
* Copy files
* Move files
* Delete files and directories
* Rename files
* Input validation and exception handling

## Skills

* Java
* Object-Oriented Programming (OOP)
* File I/O
* Java NIO
* Exception Handling

## Results

Successfully implemented a command-line tool capable of performing essential file management operations using Java.
